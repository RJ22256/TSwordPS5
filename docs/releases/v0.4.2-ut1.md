# TSword PS5 v0.4.2-ut1: past the graphics driver's start

The first run of 0.4.1 loaded the game code and linked the game, then stopped with "the console's Vulkan driver has no
vkEnumeratePhysicalDevices". UltraTears makes its Vulkan instance through the driver's own entry point, while the PS5's
screen code asked through TSword's table, which hadn't seen that instance yet. The table now takes the instance from the
call itself.

The game code is unchanged: the `tsgame.so` you exported for 0.4.1 works as it is. Only reinstall the title.
