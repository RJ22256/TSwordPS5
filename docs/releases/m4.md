**TSword PS5 - milestone 4: the game from your PC.** TSword now loads *Tears of the Kingdom*'s game code, built on your PC from your own game files by **TSword Setup** (the PC release of this repository, `TSword-Setup-pc-*-windows.zip`), and plays from the title folder.

No game files, keys or game code are included. You need your own dump of the base game and the **1.4.3** (or 1.2.1) update, and your console's `prod.keys`.

### On your PC (Windows)

1. Download **TSword Setup** from this repository's releases (the one whose notes name this PS5 release), unzip it and start `TSword-Setup.exe`.
2. Pick the base game, the update, your keys, the language and an install folder. Leave **Export for PS5** ticked.
3. Start. It builds the game for the PC first, then for the PS5 (the export takes about as long again: it compiles the game code for the console and translates every shader with the PS5's graphics settings).
4. When it's done, the install folder has a **PS5** folder.

### On the PS5

1. Copy this release's `PPSA99778` folder to `/data/homebrew/PPSA99778/` as before (replace the old one).
2. Copy **everything inside the PC's PS5 folder** into `/data/homebrew/PPSA99778/` too, beside `eboot.bin` (about 17 GB: the game files are in there; on the PC they're hard links and take no extra space).
3. Start TSword.

### If something's missing

- A notification names it: no game code yet (`tsgame.so`), one from another TSword Setup version, or the reason the game stopped. `tsword-start.log` and `logs/totk.log` in the title folder have the details.
- Shaders the export didn't translate are skipped on the console (that part of the picture is missing) and kept in `shader-cache/in/`. Copy that folder back into the PC's `PS5/shader-cache/in` and run TSword Setup again: they're translated too.

### Under the hood

- The game code is one ELF library, `tsgame.so`, loaded by the title itself before the runtime starts (a title can't load libraries the usual way); what it calls is found in the title's export table, which CI builds from a dry run of the export.
- The shaders come pre-translated: the PS5 can't run the translator, so the PC translates them with the PS5 GPU's answers (`tsword-shader-host.txt`; the console checks its own against it).
- Each TSword Setup release carries the *PS5 kit* of one TSword PS5 release (`TSword-PS5-kit.zip`): the headers, the export table and the game code id. The title refuses game code built for another release.
