**TSword PS5 - milestone 4, fix 7: room for the game's threads.**

The new log line from v0.3.7 showed why the game's thread couldn't start: plenty of memory was free (7.8 GB), but the console refused the memory for the thread's stack. TSword had already placed 30 thread stacks one after another in a part of the address space the console shares with its own reserved range, and the 31st landed right next to it.

- **The fix:** thread stacks now go in a separate, much larger part of the address space (above the game's own), where the console reliably gives out room for hundreds of them. If that ever fails, TSword tries the old place before giving up.

Copy only the new `PPSA99778` title folder. The game code and shaders on your USB drive (`TSword` folder) stay as they are.
