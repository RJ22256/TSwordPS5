## TSword PS5 0.5.7-ut1

**The `[frametime]` log line now appears.**

0.5.6 never wrote it. To leave out menus and loading, it counts only frames that draw the world, but on the PS5 it read its draw count from a part of UltraTears that always says 0. So every frame looked like a menu. It now counts the draws the console really runs.

Everything else is as 0.5.6, including **Settings → Performance → Drop to 30 when slow**.

### What your 0.5.6 log already showed
In play, frames took 33–41 ms (about 25–30 fps):
- **The game's main thread:** about 15–25 ms of work per frame, over the 16.7 ms that 60 fps needs. That's what makes the game drop itself to 30.
- **GPU:** about 9–20 ms per frame.
- **Waiting for a CPU core:** under 1 ms. The core placement from 0.5.3 is doing its job.
