## TSword PS5 0.5.0-ut1

**WSword's quick menu, settings and performance overlay come to TSword**, with frame generation.

### The menu: a two-finger tap on the touch pad
Rest two fingers on the touch pad (don't click it) and lift them. The same tap, or Circle, closes it. While it's open the game doesn't see the controller.

- **Quick menu** (rises from the bottom): Resume, **Frame rate** (30 / 40 / 60), **Resolution** (1080p / 1440p / 4K), **Frame generation**, **Performance overlay** (Off / FPS / Full), then All settings and Quit.
- **All settings** (L1 / R1 change category):
  - **Video:** resolution, 3D resolution, upscaler, sharpness, anti-aliasing
  - **Performance:** frame rate, frame generation, the overlay
  - **Controls:** button layout (Cross or Circle confirms)
  - **Quit**
- Settings are saved to `ultratears.cfg` in the title folder.
- **The overlay and frame generation change at once.** The game reads the others only as it starts, so resolution, frame rate and the rest apply **the next time TSword starts**. The quick menu lists what's waiting for a restart.

### Performance overlay
Same look as WSword's: a black card in the top right.
- **FPS:** the frame rate and the frame time.
- **Full:** CPU use, CPU and SoC temperatures, memory, a graph of frame times, and the resolution chain (e.g. `1920 x 1080 -> 3840 x 2160 | FSR 1 | FXAA`).

It replaces the old 5x7 frame counter.

### Frame generation (needs your own Lossless.dll)
Lossless Scaling's frame generation, as in WSword: 2x, 3x or 4x the frames on the TV (30 → 60 / 90 / 120; 3x and 4x need a 120 Hz TV).
- **To use it**, copy `Lossless.dll` from your Lossless Scaling install (Steam) to an **`lsfg` folder inside the title folder** (next to `tsgame.so`): `lsfg/Lossless.dll`. If WSword already has a copy at `/data/homebrew/PPSA99777/lsfg/Lossless.dll`, TSword uses that one.
- Until the DLL is there, the menu shows Frame generation as **Not available**.
- **It's off by default.** Nothing about it runs until you turn it on.
- The game's own frame is shown one frame later than without it (interpolation needs the next frame).
- **If it stops,** the reason is shown under Settings → Performance and written to the log as `[framegen]`.
- The frame generation code is lsfg-vk (GPL-3.0). See `ps5/third_party/lsfg-vk/README.TSword.md`.

### DualSense names
The game's button guide now names the shoulder and trigger buttons **L1 / L2** instead of LB / LT.

### Not done yet
- **PlayStation shapes in the game's own prompts** (✕ ○ □ △ in place of A / B / X / Y) and **the DualSense picture on Basic Controls** come next. These need the game's own textures and fonts redrawn.

### Fonts
The menu uses SST, read from the console's own system fonts (never shipped). If it can't find SST, it falls back to Inter.

**No new PS5 export is needed.** Replace the title folder's files only.
