**TSword PS5 - milestone 4, fix 10: telling a slow screen from a frozen one.**

v0.3.10 got to the game's first screens: Nintendo Presents, then "The Legend of Zelda" with sound. The picture then stayed on "The Legend of Zelda" while the game kept going (footsteps).

The log shows the next frame being built: the title scene needs many graphics programs the PS5 has never built before, and each one is built on the console the first time it's needed. Each wait was logged, up to almost a second. Built programs are kept (`pipeline-cache.bin`, `pipeline-keys.bin` in the title folder) and built ahead of time on the next start, so this gets faster with each run.

- **New:** `logs/totk.log` now gets a `[ps5] watchdog` line every 10 seconds while the picture doesn't change, and one when it moves again. That tells a slow first frame apart from a real freeze.

Please leave it on the frozen picture for 2-3 minutes before closing it, then send `logs/totk.log`.

Copy only the new `PPSA99778` title folder. The game code and shaders on your USB drive (`TSword` folder) stay as they are.
