**TSword PS5 - milestone 3, fix 3: you can see why it stops.** v0.2.2 did start. Its log shows the Tears of the Kingdom runtime running on your PS5: settings read, log opened, memory set up and services started, up to where it checks the game files. It stopped there because there's no game code yet, about a second in and before it had drawn anything, so on the TV it looked like it never started.

Now, whenever the runtime stops on an error, TSword shows a PS5 notification with the reason and waits a few seconds before closing. Without game code, the notification says that's where it stopped and that the PS5 export (milestone 4) will bring the game code from your PC.

The logs are still in the title folder: `tsword-start.log` and `logs/totk.log`.
