## TSword PS5 0.4.4-ut1

**For the console freezing at launch (again in 0.4.3).**
0.4.3's heartbeat showed that the GPU had finished its work and was idle, so the GPU wasn't stuck. In both freezing runs, the last graphics line in the log was the same: the game's main thread switching itself to real-time scheduling. That is a PC feature (macOS's time-constraint threads). On the console it made the thread SCHED_FIFO, and a FIFO thread that waits by spinning never lets other threads on its core run. The game stopped, and the console with it.

- **Real-time threads are off on the PS5.** The game's threads run at normal priority, as WSword's always have. `TOTK_PS5_REALTIME=1` in ultratears.cfg turns them back on (not recommended).
- The log now says `[ps5] real-time threads: off` at startup.
- 0.4.3's GPU watchdog, heartbeat and descriptor sets stay.

**No new PS5 export is needed.** Replace the title folder's files only.
