**TSword PS5 - milestone 4, fix 4: the game starts asking for files.**

With v0.3.4 the game itself started running on the PS5 for the first time, then stopped with `sm: service "fsp-srv" is not implemented`.

- **The cause:** TSword answers the game's file requests itself (reading the game's files from your drive instead of asking a Switch for them). Three of those answers, for mounting the game's files, are built into the game code made on your PC (`tsgame.so`), not into the title. On PC both halves are one program, so they were always found. On the PS5 the title didn't look inside `tsgame.so` for them, so the game fell through to asking the console's (non-existent) Switch file service.
- **The fix:** the title now reads those answers from `tsgame.so` when it loads it. `logs/tsword-start.log` says how many it found (3).

Copy only the new `PPSA99778` title folder. The game code and shaders on your USB drive (`TSword` folder) stay as they are.
