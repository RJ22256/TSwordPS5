**TSword PS5 - milestone 4, fix 1: the game files on an external drive.**

The PS5 folder from TSword Setup's export (about 17 GB) no longer has to go into the title folder. Copy it to a USB drive or extended storage instead, and TSword finds it there.

TSword looks in these places, in order, and uses the first that has the game (`exefs/main.npdm`):

1. a full path written as the first line of `game-files.txt` in the title folder (e.g. `/mnt/usb0/Games/TotK`)
2. the title folder itself (`/data/homebrew/PPSA99778`), as before
3. on each USB drive (`/mnt/usb0` to `usb7`) and extended storage drive (`/mnt/ext0` to `ext2`): `TSword`, `PPSA99778`, `PS5`, `TSword/PS5`, or the top of the drive

The simplest: make a folder called **TSword** on the drive and copy everything inside the PC's PS5 folder into it. `tsgame.so` can go there too, or stay in the title folder.

Saves, logs and settings stay in the title folder. The log's `[tsword] game files:` line in `tsword-start.log` says which folder was used.

Works with TSword Setup pc-0.1.0 (the game code didn't change).
