## TSword PS5 0.4.5-ut1

**For the freezes that continued in 0.4.4.**
In 0.4.4 the console stayed responsive: you could open the home screen and close TSword. That fits the 0.4.4 fix having worked, but the game was still stuck on a black screen after its first frame, and the console froze while the title was closing.

The one console-only feature left in every frozen run is the **write watch**. It changes page protection on game memory that the GPU has imported, many times a second. A process whose memory protection is tangled with the GPU's is also exactly what can lock the kernel at process exit.

- **The write watch is off by default.** Textures are compared by content instead, as in 0.4.0. This uses a little more CPU per frame and gives the same picture. `TOTK_WRITE_WATCH=1` in ultratears.cfg turns it back on (testing only).
- **The log is now also copied to your USB drive**, next to the game files (`TSword/ultratears.log`), every second and flushed to the drive. After a freeze you can unplug the drive and read the log on a PC, without starting the console twice. `TOTK_LOG_MIRROR=0` turns this off.
- The fixes from 0.4.3 and 0.4.4 stay: no real-time threads, descriptor sets, the GPU watchdog and the heartbeat.

**No new PS5 export is needed.** Replace the title folder's files only.
