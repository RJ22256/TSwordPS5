**TSword PS5 - milestone 4, fix 11: textures decoded once, not every frame.**

v0.3.11's frame check showed the title screen wasn't frozen: it was running at about one frame every 8 seconds. Almost all of that time went into decoding textures - 11,700 million texels in a few minutes, the same textures over and over.

- **The cause:** the Switch's textures use a format (ASTC) the PS5's graphics chip can't read, so TSword decodes them into one it can. It decodes a texture again only when the game changes it, and on PC it knows that from Windows/Linux telling it which memory was written to. The PS5 has no such feature, so TSword assumed every texture might have changed and decoded all of them again for every frame.
- **The fix:** on the PS5, TSword now keeps a fingerprint of each texture's data and decodes it again only when the fingerprint changes. The fingerprint covers every byte, so a texture the game really changes is still updated.

Copy only the new `PPSA99778` title folder. The game code and shaders on your USB drive (`TSword` folder) stay as they are.
