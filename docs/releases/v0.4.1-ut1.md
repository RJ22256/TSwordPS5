# TSword PS5 v0.4.1-ut1: a write watch for the PS5

The PS5 has no way to tell a program which memory it wrote, so 0.4.0 compared every texture's contents to spot changes
(up to 16 MB of hashing per submission), and treated index buffers and the GPU's write-backs as changed every time.

0.4.1 builds its own: game memory the graphics code checks is made read-only (its GPU access kept), and the first write
to a page is caught, marked and let through. Pages the game writes every frame are left writable after a few rounds, so
the faults stay few. Kernel writes (file reads) and the GPU driver's imports are handled before they happen.

It was tested on Linux with the console's calls stood in for: up to 16 threads writing while another checks, about 490
million writes, none missed. It hasn't run on a PS5 yet.

- Every 10 s `ultratears.log` gets a `[ps5] write watch:` line (writes caught per second, how much memory is read-only).
- If textures that should change stay old, or it misbehaves, add `TOTK_WRITE_WATCH=0` to `ultratears.cfg` to go back to
  0.4.0's content checks, and send the log.

The game code is the same as 0.4.0's (same game code id): a `tsgame.so` exported for 0.4.0 works as it is, so only the
PS5 title needs updating.
