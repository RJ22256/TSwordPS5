**TSword PS5 - milestone 1: the console check.** This isn't the game yet. It's a TSword title for a jailbroken PS5 that boots, draws on the GPU, and checks what the Tears of the Kingdom recompilation's runtime needs on your console.

1. Unzip `TSwordPS5-PPSA99778.zip` and copy `PPSA99778` to `/data/homebrew/PPSA99778/` over FTP. It sits beside WSword's `PPSA99777`.
2. With ShadowMountPlus loaded, **TSword** appears on the home screen with its green icon. Start it.
3. Press OPTIONS or the touch pad to show its window, **TSword PS5 - console check**, which lists anything missing.
4. Send back `/data/homebrew/PPSA99778/tsword-check.txt` (over FTP).

It checks:
- the Vulkan 1.3 extensions the runtime uses, above all host-memory import
- the game's memory layout below 2^39: a 6 GB block and a 64 GB alias region, part of it backed and imported into Vulkan
- write-protection faults
- a signal to a busy thread
- the CPU and the title folder
