## TSword PS5 0.5.2-ut1

**⚠ This release needs a new PS5 export.** Run `Export for PS5.bat` from this release's `TSword-PS5-export.zip`. The game data isn't copied again, so it's mostly the 10–30 minutes of translating and compiling.

### What 0.5.1 changed
With Speed-ups on, the log shows frames are usually on time at the 60 limit. In the slow frames (median 38 ms):
- **The game's own work on its main thread: about 24 ms**
- **GPU: about 15 ms** (at a 1600×900 scene)
- **Waiting for a core:** a thread can wait up to 125 ms behind a less urgent one

### What's new
- **The game code is optimized with UltraTears' profile of it.** The PC version already builds its game code this way. The profile records how often each function ran and which way its branches went, from a 20-minute play session; it contains none of the game's code. The compiler lays out and inlines the code by it; nothing behaves differently.
  - On the Steam Deck it cut the game's work per frame from 23–24.6 ms to 21–22.6 ms.
  - To make the profile match, the PS5's translated functions now use the PC's names. That's why a new export is needed.
  - The export window says `the game code optimized by the PC's profile` when it's used. If your UltraTears' clang can't read it, the window says so and builds without it.
- **Settings → Performance → Thread preemption (experimental, off by default):** a more urgent game thread takes its core at once instead of waiting. This targets the 50–125 ms hitches.
  - In 0.4.2–0.4.5 TSword froze with it on, but other faults were behind those freezes and have since been fixed.
  - **If the console freezes with it on**, remove the `TOTK_ASYNC_PREEMPT=1` line from `ultratears.cfg` over FTP.
  - It applies at the next start.
