**TSword PS5 - milestone 4, fix 9: the save folder.**

v0.3.9 reached the game: the Nintendo Presents screen played, then sound (Link's footsteps) over a black screen. On the next start it stopped at `fs: cannot delete the old save working copy: /app0/profile/save-tx/work (OS error 66)`.

- **The cause:** to keep your save safe, TSword writes it in a working folder first and clears that folder on the next start. Clearing it lists what's inside and deletes each file, but the PS5 refused one of the questions TSword asks about each file, so the files were skipped and the folder couldn't be removed ("not empty").
- **The fix:** when the PS5 refuses that question, TSword asks the plain version (and falls back to the file type the folder listing gives). If a folder still can't be removed, `logs/tsword-start.log` lists what's left in it.

The black screen after Nintendo Presents is the next thing to look at: please send `logs/totk.log` from a run that gets there.

Copy only the new `PPSA99778` title folder. The game code and shaders on your USB drive (`TSword` folder) stay as they are.
