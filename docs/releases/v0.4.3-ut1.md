## TSword PS5 0.4.3-ut1

**For the console freezing at launch.**
0.4.2 got past Vulkan and recorded its first frame. Then the game stopped, and the console locked up until the power button was held. That is how a GPU that never finishes its work looks on the PS5.

- **Descriptor sets by default.** The console's RADV has run WSword on descriptor sets for months; its descriptor buffers had never drawn a frame before TSword, so they are the likeliest cause. The picture is the same either way. `TOTK_VK_DESCRIPTOR_SETS=0` in ultratears.cfg goes back to buffers.
- **A GPU watchdog.** If a GPU submission runs past 3 s, the log says so. At 8 s TSword ends itself with an error message rather than waiting forever, and writes the log first. Exiting may let the console recover without a hard power-off. `TOTK_GPU_WATCHDOG=0` turns it off.
- **A heartbeat in ultratears.log.** Every 10 s the log shows how many GPU submissions have finished and the present count, so a log shows how far the game got.
- `gpu_marks=1` in ultratears.cfg makes a stop name the GPU commands that were running (slightly slower; only for testing).

**No new PS5 export is needed.** The game code is unchanged; replace the title folder's files only.
