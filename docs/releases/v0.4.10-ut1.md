## TSword PS5 0.4.10-ut1

**The game got past its startup logo** (0.4.8: `game finished startup logo`, frame 36). Then frames took 1–4 s each, and at frame 47 it stopped.

**Why: the log.** Each log line was written to the file by the thread that logged it, and on the console a write took up to seconds (`log 4 writes / 3794 ms` in the long-frame lines). The main thread's blocked time matched the frame times, and even the stall report took two minutes to print. The game was waiting for its own log.

- **The log is written by a thread of its own.** Lines go into a 4 MiB ring in memory and that thread writes them to the file, so game threads never wait on the drive. If the file falls 4 MiB behind, lines are dropped and the log says how many bytes. Before an error ends the title, the ring is written out first.
- **The USB copy of the log syncs every 5 s** instead of every second.
- **From 0.4.9:** the title folder's `data/shaders` is created, so compiled shaders are kept between starts.

The first start after installing still compiles the startup shaders (a few minutes); later starts load them.

Safe mode stays. **No new PS5 export is needed.** Replace the title folder's files only.
