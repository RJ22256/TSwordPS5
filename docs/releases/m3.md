**TSword PS5 - milestone 3: the first link.** TSword's eboot is now the Tears of the Kingdom recompilation's runtime itself, built for the PS5. There's no game yet: the game code comes from your PC in milestone 4.

1. Unzip `TSwordPS5-PPSA99778.zip` and copy `PPSA99778` over the console-check folder at `/data/homebrew/PPSA99778/`, replacing the files.
2. Start **TSword**. The runtime starts: it reserves the game's memory, reads its settings and opens its log. When it reaches the point where it needs the game, it shows a notification ("No game code yet") and closes itself.
3. Send back `/data/homebrew/PPSA99778/totk.log`. It shows how far the runtime got on your console.

What's in it:
- TotK Recomp 0.4.0's runtime, compiled for the PS5. Its platform layer puts the game's memory, thread stacks and fibers on the console's direct memory and handles crashes.
- WSword's PS5 SDL layer, plus what this runtime needs: the window, DualSense input and motion, and audio.
- The audio, video and compression libraries (opus, libvpx, zstd), built for the console.
