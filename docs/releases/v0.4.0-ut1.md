# TSword PS5 v0.4.0-ut1: rebuilt on UltraTears

TSword is now built on UltraTears (kuraeow/ultratears, commit d657eff), with the console layer done the WSword PS5 way:
memory backed on first touch, textures checked for changes, the game code built on your PC and loaded by the title.
TotK Recomp is gone.

## Install

1. On your PC, set up UltraTears (its own release, `tools/setup.py`, your TotK 1.4.3 dump). Using the same UltraTears
   commit as this release (d657eff) is safest.
2. Unzip **TSword-PS5-export.zip** and double-click **Export for PS5.bat**. Give it your UltraTears folder and a folder
   on an exFAT USB drive (e.g. `E:\TSword`). It translates the code for the PS5 (10 to 30 minutes the first time),
   builds `tsgame.so` and copies the game data (about 30 GB).
3. Install **TSwordPS5-PPSA99778.zip** on the PS5 as before, plug in the drive and start TSword. It finds `TSword\` on
   the drive by itself.

Settings: `ultratears.cfg` in the title folder (1080p, 30 fps, vsync on, cross as A by default). Log:
`ultratears.log` there.

## What to expect

This is the first console build of UltraTears and hasn't been run on a PS5 yet. Shaders are compiled on the console
the first time they're seen, so expect stutters early on. If it stops, the reason appears on screen and in
`ultratears.log`; please send the log.
