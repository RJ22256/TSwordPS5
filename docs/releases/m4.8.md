**TSword PS5 - milestone 4, fix 8: the profile folder.**

v0.3.8 got past the threads: the game's audio started (48 kHz stereo on the TV). Then it stopped at `fs: cannot create directory /app0/profile` - a folder that was already there (an earlier run made your local account in it).

- **The cause:** asking the PS5 to create a folder that already exists in the title folder gives a different answer than on PC, which TSword read as a failure.
- **The fix:** when the PS5 says no, TSword now checks whether the folder is already there and carries on if it is. If creating a folder really fails, `logs/tsword-start.log` now says why.

Copy only the new `PPSA99778` title folder. The game code and shaders on your USB drive (`TSword` folder) stay as they are.
