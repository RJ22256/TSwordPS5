**TSword PS5 - milestone 4, fix 3: the silent crash after the shaders.**

Your last log showed that everything up to the shaders now works: the files on the USB drive, the game code, the GPU and the shader cache with the right identity. Then TSword closed without an error on screen.

- **The cause:** when TSword makes one of its own tables read-only (the 74 MB table that sends the game's calls to the right code), it also wrote a note about that memory into its record of the Switch's memory. That memory was never the Switch's, so the record had no space there, and the console stopped TSword.
- **The fix:** the record now only keeps notes about the Switch's memory, as on PC. TSword's own memory is left out.

Copy only the new `PPSA99778` title folder. The game code and shaders on your USB drive (`TSword` folder) stay as they are.
