**TSword PS5 - milestone 4, fix 5: the game's own start-up code in tsgame.so.**

With v0.3.5 the game read its files from your USB drive (304,243 files, RomFS ready in 0.68 s), then stopped at `rt_dispatch: no function at guest pc 0x7003adfff0`.

- **The cause:** some of TSword's parts in `tsgame.so` set themselves up automatically when the game code loads. One of them is the fast decompressor the game uses to unpack its files (the address in the error); another is the camera's direct mouse input. The PS5 compiler marks those start-up steps in a different way than PC compilers, and the title's loader only knew the PC way. So they never ran, and the game's first unpack went nowhere.
- **The fix:** the loader now runs those start-up steps the PS5 way too.

Copy only the new `PPSA99778` title folder. The game code and shaders on your USB drive (`TSword` folder) stay as they are.
