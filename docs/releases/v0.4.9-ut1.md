## TSword PS5 0.4.9-ut1

**TSword runs.** In 0.4.8's log the game reached frame 30 and kept going. The black screen is the game's startup while the driver compiles its shaders: about 70 a second, thousands in all on a first start.

**Fixed: the compiled shaders are kept now.** The console's binaries go to `data/shaders/compiled-ps5.bin` in the title folder, but that folder didn't exist, so they could never be written ("cannot write …: shaders are compiled every run") and every start compiled everything again. The folder is created at startup, and the binaries are synced every 2 s (0.4.8), so a later start loads them instead of compiling.

**The first start after installing this is still the long one.** Let it run; the log's `shaders:` line counts up. Later starts should get to the game much sooner.

Safe mode stays. **No new PS5 export is needed.** Replace the title folder's files only.
