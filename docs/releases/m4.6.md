**TSword PS5 - milestone 4, fix 6: the console's memory, and why a thread can't start.**

With v0.3.6 the game got much further: the fast decompressor ran, textures started decoding on the GPU, your controller and a local account were set up. Then it stopped with `kernel: cannot start a guest thread` while the game was starting one of its own threads.

- **Memory the game can see:** TSword asks the system how much memory is left, so it can hold back (e.g. not allocating graphics memory ahead of time, giving textures back) when memory runs short. On the PS5 that question had no answer, so TSword acted as if memory never runs out. It now asks the console for its free memory, the way it does on a Linux PC with one shared memory for CPU and GPU.
- **A clear reason if it happens again:** if a thread still can't start, `logs/tsword-start.log` now says exactly why (the step that failed, its error code, and how much memory was free), and the crash line in `logs/totk.log` shows the memory in use instead of -1.

Copy only the new `PPSA99778` title folder. The game code and shaders on your USB drive (`TSword` folder) stay as they are.
