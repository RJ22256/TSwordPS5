**TSword PS5 - milestone 3, fix 2: two launch blockers removed.** v0.2.1 still went back to the home screen right after its splash, before running any of its own code, so there was no log. It was the only build to import two things WSword's title never does:

- **`__stack_chk_guard`**, a data import from the system's kernel library, which the opus audio library's stack protector brought in. opus is now built without it.
- **`libSceRandom`**, a system module my platform layer used for random numbers. It now uses the CPU's own random-number instruction (RDRAND) instead.

TSword now imports exactly the console libraries WSword does.

What to expect: TSword starts, shows a notification ("No game code yet") and closes itself after a few seconds. The game code comes from your PC in milestone 4.
