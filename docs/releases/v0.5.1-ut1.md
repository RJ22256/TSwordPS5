## TSword PS5 0.5.1-ut1

**Speed: the graphics move off the game's thread.**

### What the 0.5.0 log showed
In play, each frame took 50–75 ms (about 15–20 fps):
- **GPU: 4–9 ms.** The GPU is mostly idle, so 1080p isn't what's holding it back.
- **Replaying the game's graphics: 20–55 ms**, done on the game's own thread. Safe mode (0.4.7) had put it there while we were chasing the freezes, and it also wrote a GPU marker before every draw, which kept recording on one thread.

The freezes' causes were found and fixed after that. Safe mode was still costing about half of every frame.

### What changes: Speed-ups (Settings → Performance)
- **Balanced (the new default):** what the PC version runs.
  - The game's graphics are translated on their own thread and recorded on three.
  - Commands go to the GPU in parts as they're recorded.
  - No GPU markers.
- **Full:** also compiles shaders, reads textures and makes memory ahead, on their own threads.
- **Safe:** 0.5.0's way. Slow, for if the others misbehave.

It applies at the next start. Every level keeps what TSword needs to be correct on the console: the game's memory imported for the GPU, pools kept, robust GPU reads.

**If Balanced freezes or crashes at start** (before you can open the menu), add the line `speedups=safe` to `ultratears.cfg` in the title folder over FTP, and send the log.

The log's first lines now say which level is in use: `[tsword] speed-ups: balanced ...`.

### To try after this
With the GPU this idle, 1440p (or even 4K) may cost little once the CPU side is faster. Turn on the performance overlay (Full) and compare.

**No new PS5 export is needed.**
