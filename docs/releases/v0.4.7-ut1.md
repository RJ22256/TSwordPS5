## TSword PS5 0.4.7-ut1 — safe mode

Everything optional that could stop the game is switched off on the console, while TSword still stops after its first frame.

**On top of 0.4.3–0.4.6** (no asynchronous preemption, no real-time threads, no write watch, descriptor sets):
- **No virtual cores** (`TOTK_FREE_CORES=1`): game threads are ordinary console threads, so no thread can be stuck waiting for a core.
- **No translation thread** (`TOTK_ASYNC_REPLAY=0`): graphics are replayed on the game's own thread.
- **One recording thread**, and **each submission sent in one call** (no partial submission).
- **No helper threads**: no memory made ahead, no shaders compiled ahead, no texture prefetch.
- **Plain write-back** of GPU-drawn images (no fence write-back), and **memory pools kept** until the game releases them.
- **Robust GPU buffer reads**: an out-of-range read returns 0 instead of faulting the GPU.

These cost some speed and change nothing in the picture. The log says `[tsword] safe mode: N settings at their plainest`.

**Controls in ultratears.cfg:** a line naming any of these settings wins, e.g. `TOTK_FREE_CORES=0` brings the virtual cores back. `TOTK_SAFE_MODE=0` turns the whole safe mode off.

Still on: the stall report after 10 s without a frame, the log copy on the USB drive, the GPU watchdog and the heartbeat.

**No new PS5 export is needed.** Replace the title folder's files only.
