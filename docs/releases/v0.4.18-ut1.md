## TSword PS5 0.4.18-ut1

**TSword got into the game.** With the game files on the console's own SSD (`game files: the title folder`), 0.4.17 loaded the opening and played a few seconds. Then the game's first save stopped it:

`save write at 0 (0x233710 bytes from 1071aa54d0) failed: errno 14` → `FATAL: host save write failure`

**Why:** on the console, game memory is backed only when it's first touched. When the kernel itself reads memory the game hasn't touched yet, it doesn't fault; it fails with EFAULT (errno 14). Reads *into* game memory already backed their buffer first. The save **write** didn't, so the kernel couldn't read the save data out of game memory.

- **Fixed:** the save buffer is backed before the write, and an EFAULT is retried after backing again, the same way file reads already work.

**No new PS5 export is needed.** Replace the title folder's files only.
