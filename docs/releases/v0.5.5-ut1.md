## TSword PS5 0.5.5-ut1

**Turning on frame generation no longer changes the frame rate.**

0.5.4 set the game to 30 whenever frame generation was turned on. Generating from 30 fps ghosts in fast motion: the frames are far apart, and the made ones have to guess more. So it now leaves the frame rate as you set it.

The Frame generation row now says what it's best with: a 120 Hz TV, with the game at 40 (3x) or 60 (2x).

No new export beyond 0.5.2's. Replace the title folder's files.
