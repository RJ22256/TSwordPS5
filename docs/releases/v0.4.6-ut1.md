## TSword PS5 0.4.6-ut1

**For the game stopping after its first frame (0.4.2 to 0.4.5).**
0.4.5's log showed that turning off the write watch and real-time threads didn't change anything: the game still stopped at the same point. One console-only mechanism is left that was on in every run: **asynchronous preemption**. It sends signals to game threads to take their virtual core away, and those signals can land anywhere, including inside a system call to the graphics or video output. WSword has never had it.

- **Asynchronous preemption is off on the PS5.** A thread now gives up its core at its next system call or indirect call, as UltraTears did before preemption existed. This can cost the occasional hitch while the world streams in; it doesn't change the picture. `TOTK_ASYNC_PREEMPT=1` in ultratears.cfg turns it back on (testing only).
- **A stall report.** If the game makes no new frame for 10 s, the log lists every game thread: what it waits for, the virtual core it holds, its last system call and the game function it came from. So if it stops again, the log says where.
- Kept from 0.4.3–0.4.5: the log copy on the USB drive, no real-time threads, no write watch, descriptor sets, the GPU watchdog and the heartbeat.

**No new PS5 export is needed.** Replace the title folder's files only.
