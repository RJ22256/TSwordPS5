## TSword PS5 0.4.15-ut1 — a fix for the freeze after "The Legend of Zelda"

**What 0.4.14 showed:** every GPU job had finished (587 of 587). The thread replaying the game's graphics was stuck while building the next one, and **it didn't even answer a signal**, which means it was stuck inside the console's kernel. That happened right as the opening scene needed shaders it hadn't used yet.

**The cause:** the 888 MiB shader pack on the USB drive was **memory-mapped**. A shader used for the first time was read out of the mapping by page faults: a disk read inside the kernel, which no signal can interrupt, from the same USB drive the game reads its files from. The BC7 texture cache was mapped the same way. One of those reads never came back, and the console froze with it. That fits every log since 0.4.11.

- **The shader pack is read, not mapped:** its index (2.7 MiB) goes into memory once, and each shader's bytes are read with `pread` when needed. The log says `(read as needed, not mapped)`.
- **The BC7 cache is read, not mapped**, too (its existing read path).

Safe mode, the saved shaders and all the diagnostics stay.

**No new PS5 export is needed.** Replace the title folder's files only.
